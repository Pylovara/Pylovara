# Kapitel 1: Der Zauberrand (Transaktionsrahmen)

Hallo kleiner Entwickler! 🌟

Heute lernen wir etwas ganz Wichtiges. Weißt du, was passiert, wenn man im Wald eine ganz besondere Entdeckung macht? Man möchte einen Schutzzaun darum bauen, damit alles sicher ist und man in Ruhe schauen kann, was im Wald passiert.

In Pylovara nennen wir das einen **Transaktionsrahmen**. Aber wir sagen dazu einfach: **Der Zauberrand**.

```text
        .   *   .    *    .  *      .    * 
       *    .  / \  *  . / \  .  * / \  .  *
      .  *    /   \  .  /   \  *  /   \    .
    *      --|     |---|     |---|     |--     *
  .    *     |     |   |     |   |     |  .  *
             |     |   |     |   |     |
      _______###########################_ 
     /                                   \
    |     ***************************     |
    |     *                         *     |
    |     *   ¢! ["Der Hase"] !¢    *     |
    |     *                         *     |
    |     *         (\_/)           *     |
    |     *         (z.z)           *     |
    |     *        (>  <)           *     |
    |     *     schläft tief...     *     |
    |     *                         *     |
    |     ***************************     |
     \_________________#_________________/

          /------------#-----------\
         /  [ OVERHEAD PROJECTOR ]  \
        /____________________________\
              /                  \
             /                    \

           /     (^_^)    (o_o)     \
          /    squirrel |  owl       \
```

Alles, was innerhalb dieses Randes passiert, gehört zusammen. 
Es ist wie eine kleine Insel, auf der deine Befehle ganz 
sicher sind.

## Der magische Anfang: ¢!

Damit der Zauber beginnt, brauchen wir ein spezielles Zeichen 
am Anfang. Es sieht so aus:

# ¢!

Stell dir vor, das **¢** ist ein kleiner magischer Schlüssel 
und das **!** sagt: "Achtung! Jetzt geht der Zauber los!"

## Das Ende vom Zauber: !¢

Wenn wir fertig sind, müssen wir den Rand wieder zumachen. 
Das machen wir so:

# !¢

Hier kommt erst das **!**, um zu sagen: "Stopp, wir sind fertig!",
und dann der Schlüssel **¢**, der den Zauber sicher abschließt.

---

### Deine Aufgabe:
1. Kannst du die Zeichen `¢!` und `!¢` in die Luft malen?
2. Male ein Bild von deiner Lieblings-Sache (zum Beispiel 
einen Apfel oder einen Hund) und zeichne einen leuchtenden
 Zauberrand mit `¢!` und `!¢` darum herum!

Denk dran: Alles, was **zwischen** `¢!` und `!¢` steht, ist 
in Sicherheit!

> [!TIP]
> **Für Eltern:** Helfen Sie dem Kind, die Symbole `¢` und `!` 
> auf der Tastatur zu finden oder malen Sie gemeinsam ein großes
> Plakat mit dem "Zauberrand". Es geht darum, das Konzept von
> "Start" und "Ende" eines geschlossenen Logik-Bereichs zu 
> verstehen.

> Wenn sie mit einem Computer arbeiten , stellen sie sicher das 
> sie utf -8 Deutsche Standart haben !

> *Tip= Wenn einmal verstanden wurde wie man jedes Zeichen 
> ansteuern kann, ist das schreiben mit MCS ein Kinderspiel

> Sie finden die das cent zeichen unter Rechtes Alt + C = ¢ und 
> das Ausrufezeichen unter Shift + 1 = !
> Besser wäre es wenn sie Schriftlich arbeiten auf Originalem 
> Weisen Blätter oder auf einem Whiteboard !
